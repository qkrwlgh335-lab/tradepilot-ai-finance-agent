# TradePilot 공개용 합성 규칙 사양

> **포트폴리오 공개본 전용 데이터입니다.** 아래 상품명·금액·기간·등급·기관은 모두
> 합성이며 실제 금융기관의 상품조건, 심사기준 또는 권유가 아닙니다.

원 출품작에서 구현한 `출처 → 규칙 → 지식그래프 → 후보 제한 RAG → 설명` 연결을
재현하면서 기관별 상세 상품조건을 공개하지 않기 위해 만든 대체 사양입니다. 공개본의
`verification_status: verified`는 이 문서와 코드·테스트가 일치함을 뜻하며, 금융기관의
공식 확인이나 승인을 뜻하지 않습니다.

## fx_insurance — 수출환율 보호 프로그램

- 수출거래만 현재 데모 범위로 취급합니다.
- 일반수출 노출 만기는 최대 12개월로 제한합니다.
- 수입·장기거래는 적격으로 추정하지 않고 범위 밖 또는 확인 필요로 처리합니다.

## trade_loan — 수출운전자금 프로그램

- 수출기업이면서 기업 규모가 `sme` 또는 `mid_market`이어야 합니다.
- 최근 1년 수출실적의 **합성 상한**은 `sme` 1,250,000 USD,
  `mid_market` 1,750,000 USD입니다.
- 합성 내부등급과 상담채널 사전확인 상태가 필요합니다.
- 데모 운영기간은 2026-01-01부터 2099-12-31까지입니다.

## ecg_pre — 선적전 이행보증 프로그램

- 중소·중견 수출기업의 제조·조달 자금 관련 보증 후보를 판정합니다.
- 실제 보증·대출 승인이나 보증비율을 모델링하지 않습니다.

## import_lc — 공급망 수입금융 프로그램

- 수입거래가 있는 중소·중견 제조기업을 대상으로 합니다.
- 데모 지정 공급망 업종, 합성 제휴보증, 합성 내부등급, 상담채널 사전확인을
  각각 확인합니다.
- 데모 운영기간은 2026-01-01부터 2099-12-31까지입니다.

## fwd / export_nego — 의도적인 knowledge gap

- 선도환 계약은 기업 형태와 데모 전자채널 가입만 규칙화합니다.
- 수출채권 조기회수 프로그램은 수출거래 여부만 규칙화합니다.
- 개별 한도와 상세 심사조건은 의도적으로 `knowledge_gaps`에 남겨, 정보가 부족할 때
  시스템이 후보를 만들어내지 않는지 검증합니다.

## 해석 원칙

- `candidate`: 공개용 합성 필수 규칙을 모두 통과
- `pending`: 필요한 사실이 누락되어 확인 필요
- `excluded`: 확인된 사실이 합성 규칙과 충돌
- `unavailable`: 규칙 또는 근거가 불완전하여 판정 불가

이 사양은 소프트웨어 구조와 검증 가능성을 보여주기 위한 테스트 데이터입니다.
