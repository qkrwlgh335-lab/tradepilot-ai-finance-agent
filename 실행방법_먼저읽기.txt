KB TradePilot 실행방법
=======================

가장 쉬운 실행 방법
1. 실행코드 폴더를 엽니다.
2. START_DEMO.cmd를 더블클릭합니다.
3. 잠시 뒤 브라우저에서 http://127.0.0.1:8000 이 자동으로 열립니다.

주의
- index.html을 직접 더블클릭하면 데이터 파일을 읽을 수 없어 정상 실행되지 않습니다.
- Node.js 18 이상이 필요합니다.
- 일반 데모에는 npm install, 외부 API 키, Claude 구독이 필요하지 않습니다.
- 서버를 종료하려면 작업표시줄에 최소화된 "KB TradePilot Server" 창을 닫습니다.

수동 실행
1. 실행코드 폴더에서 터미널을 엽니다.
2. node scripts\dev-server.mjs
3. 브라우저에서 http://127.0.0.1:8000 접속

권장 데모
A사 샘플 불러오기 → 기업정보 입력 → 기존 헤지 없음 확정 →
분석하기 → 입력 확인 → 분석 실행 → 상세 분석 → 자기반례 →
상품 후보 선택 → 상담 신청서·브리프 생성

선택적 외부 AI 설명 기능(필수 아님)
----------------------------------
- 핵심 계산·자격판정·RAG·상담 브리프는 API 키 없이 실행됩니다.
- 실제 API 키는 제출물에 포함되어 있지 않으며,
  심사자가 본인의 Anthropic API 키를 직접 입력해야 합니다.
[방법 1] 외부AI_설정후_실행.cmd 더블클릭 (권장)
  1. 메모장이 자동으로 열립니다.
  2. ANTHROPIC_API_KEY= 뒤에 본인의 키를 붙여넣고 저장 후 메모장을 닫습니다.
  3. 앱과 로컬 프록시가 자동으로 시작됩니다.
[방법 2] .env 파일 수동 생성
  1. .env.example 파일을 복사해 .env 로 이름을 변경합니다.
  2. .env 파일에서 ANTHROPIC_API_KEY 값을 본인의 키로 입력하고 저장합니다.
  3. START_DEMO.cmd를 더블클릭합니다.
기타 안내
- ANTHROPIC_MODEL 기본값(claude-3-5-haiku-20241022)은 미리 들어 있으며,
  계정에서 지원되지 않을 때만 다른 모델 ID로 변경하세요.
- 결과 화면의 고급 설정에서 '외부 AI 설명'을 선택하고 전송 내용을 확인·승인합니다.
- 이후에는 START_DEMO.cmd만 실행해도 유효한 .env를 감지해 프록시를 자동 시작합니다.
- 키·프록시·네트워크가 없거나 호출이 실패하면 로컬 규칙 설명으로 자동 전환됩니다.
- API 키를 브라우저 화면, 소스 코드, README에 직접 입력하지 마십시오.
